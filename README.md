Welcome to the **Data Warehouse and Analytics Project** repository 🚀

---

## 🏗️ Data Architecture

![Data Architecture](https://github.com/Mahak313/DataWareHouse_Project/raw/main/Data_Planning/HIGH%20LEVEL%20ARCHITECTURE.png)

The project follows the **Medallion Architecture** pattern with Bronze, Silver, and Gold layers to ensure scalability, data quality, and analytical performance.

### Architecture Layers

**Bronze Layer**  
- Stores raw data exactly as received from source systems  
- Data is ingested from CSV files into a SQL Server database  

**Silver Layer**  
- Performs data cleaning, validation, standardization, and transformation  
- Resolves data quality issues and prepares data for analysis  

**Gold Layer**  
- Contains curated, business-ready datasets  
- Designed using a **Star Schema** optimized for reporting and analytics

## 🚀 Project Requirements

### Data Warehouse (Data Engineering)

**Objective:**  
Build a centralized data warehouse using SQL Server to consolidate sales data and support analytical reporting.

**Specifications:**  
- Data Sources: Two source systems (ERP and CRM) provided as CSV files  
- Data Quality: Cleaning and resolving inconsistencies before analysis  
- Integration: Merging data into a single analytical data model  
- Scope: Focus on the latest available data (no historization)  
- Documentation: Clear and structured documentation for data models  

### BI & Analytics (Data Analysis)

**Objective:**  
Develop SQL-based analytics to generate insights related to:  
- Customer Behavior  
- Product Performance  
- Sales Trends  

These insights support data-driven decision-making for business stakeholders.  

More details are available in `docs/requirements.md`.
